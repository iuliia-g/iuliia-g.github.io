🔧 Tool Inventory System

Equipment and room inventory management system developed using PHP, MySQL, HTML, CSS and JavaScript.

View project details

A full-stack equipment and room inventory management system developed using PHP and MySQL.

The application supports three user roles: Student, Teacher and Administrator.

Login

Users can log in according to their role. The system supports separate access for students, teachers and administrators.

User Registration

New users can register for the system. The registration process creates a user account that can later be used to access the appropriate dashboard.

Room Inventory

Users can view equipment available in specific rooms. QR codes can be used to quickly access room information.

Equipment Booking

Students can reserve equipment for their use. The booking system helps track which equipment is currently reserved.

Equipment Return

Equipment returns can be recorded in the system, allowing the inventory status to be updated.

Student Dashboard

The student dashboard provides access to equipment, room information and the student's own bookings.

Teacher Dashboard

Teachers can view and manage equipment usage and monitor student bookings.

Administrator Dashboard

Administrators have access to system management, including users, rooms, equipment and database records.

Events

The system includes event-related functionality for managing equipment and activities.

Database

The application uses a MySQL database to store users, rooms, equipment, bookings and other system data.
