🔧 Tool Inventory System

Equipment and room inventory management system developed using PHP, MySQL, HTML, CSS and JavaScript.

View project details

Overview

A full-stack web application designed for managing tools, classrooms and equipment in an educational environment. The system supports multiple user roles and allows tracking, booking and administration of inventory through a centralized database.

Technologies

  • PHP
  • MySQL
  • HTML5
  • CSS3
  • JavaScript
  • Sessions & Authentication

Features

  • User registration and login
  • Role-based access control
  • Student dashboard
  • Teacher dashboard
  • Administrator dashboard
  • Equipment management
  • Room management
  • Equipment booking system
  • Equipment return tracking
  • QR code equipment lookup
  • MySQL database integration

User Roles

Student

  • Browse available equipment
  • View room inventory
  • Reserve equipment
  • Manage own bookings

Teacher

  • Manage student bookings
  • Approve and monitor equipment usage
  • View inventory information

Administrator

  • Create and manage users
  • Add, edit and remove equipment
  • Manage rooms
  • Manage database records
  • Full system administration
